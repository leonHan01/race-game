# DUSTLINE · 尘途拉力

[English](README.md) · **简体中文**

一款以自然山野为背景的 3D 浏览器拉力竞速游戏。在砂石山道、松林、红岩峡谷与积雪山口间穿行，驾驶你选择的赛车，与 5 位 AI 车手争夺冲线名次，刷新个人赛段成绩。

使用 **Three.js、TypeScript 和 Vite** 开发。游戏菜单、HUD 与可选领航员语音目前为中文，项目提供中英文两版说明文档。

## 游戏特色

- **六车同场竞速**：5 位 AI 对手使用不同车型与驾驶节奏，会弯前制动、跟车和寻找空位超车。
- **四张不同难度的地图**：从绿谷到雪岭，路宽 14–22 米，各有不同的弯道、地貌和抓地力。
- **四类可选车辆**：前驱小钢炮、四驱拉力车、后驱跑车和越野皮卡，操控各有特点。
- **手动控制车头方向**：转向输入平滑过渡，没有自动转弯或自动回到路中央。
- **按住空格持续手刹**：按得越久，侧滑角度逐渐增大；松开后逐渐恢复抓地力。
- **平稳的道路视角**：提供追尾和低位镜头，车辆运动经过插值，不添加画面抖动或悬架弹跳。
- **竞速与计时挑战**：实时名次、冲线顺序、五个分段成绩、完赛奖牌和本地最佳纪录。
- **山野拉力氛围**：自然光照、程序生成的场景与赛车、尘土尾流、渐隐胎痕、引擎声和领航员路书。

## 快速开始

运行环境：

- Node.js **20.x 分支的 20.19+，或 22.12 及以上版本**。
- npm。
- 支持 **WebGL 2** 且开启硬件加速的浏览器。

在项目目录执行：

```bash
npm ci
npm run dev
```

打开 **[http://localhost:5175/](http://localhost:5175/)**。

开发端口固定为 `5175`。如果端口已被占用，Vite 会明确报错，不会自动切换。请通过 Vite 访问游戏，直接双击文件系统中的 `index.html` 无法正确启动。

构建并预览生产版本：

```bash
npm run build
npm run preview
```

构建结果位于 `dist/`，预览地址以终端输出为准。需要发布时，可将 `dist/` 部署到静态网站托管服务。字体随项目打包，场景资源在本地生成，游戏运行时不依赖远程模型或图片服务。

## 操作方式

| 操作 | 键盘 |
| --- | --- |
| 油门 | `W` / `↑` |
| 刹车 | `S` / `↓` |
| 左转 / 右转 | `A` / `D`，或 `←` / `→` |
| 持续手刹 / 漂移 | 按住 `Space`，松开后恢复抓地力 |
| 切换追尾 / 低位镜头 | `C` |
| 救援回赛道 | `R`，计时罚时 5 秒 |
| 暂停 / 继续 | `Esc` / `P` |

触屏设备提供转向、油门、刹车和手刹按钮。设置中可以开启自动油门，专注转向和制动；自动油门不会替你转弯。

在主菜单点击「选择地图」或「选择车辆」，再点击「开始赛段」。比赛中需要先返回主菜单，才能切换地图或车辆。

## 车库

下表为车辆完好时的最高速度。车损会降低极速，所有车型的速度上限均不超过 **250 km/h**。

| 赛车 | 类型 / 驱动 | 最高速度 | 操控特点 |
| --- | --- | --- | --- |
| SWIFT F2 | 小钢炮 / 前驱 FWD | 220 km/h | 轻巧、抓地力强、甩尾温和 |
| FALCON R4 | 拉力车 / 四驱 AWD | 250 km/h | 加速、转向与漂移均衡 |
| COMET RS | 跑车 / 后驱 RWD | 250 km/h | 加速迅猛、侧滑幅度大，需要及时反打 |
| NOMAD T4 | 越野皮卡 / 四驱 AWD | 210 km/h | 耐损、路外减速较少，转向较慢 |

玩家赛车提供砂岩白、森林绿、竞赛红三种涂装。浏览器存储可用时，地图、车辆、涂装与驾驶偏好会自动保存。

## 竞速与漂移规则

六辆车在同一倒计时结束后起步。AI 会依据前方弯道与路面抓地力调整速度，选择相邻空位超车，或在前车后方减速跟随。专业模式下，对手的驾驶节奏更快。

HUD 显示实时名次和对手距离，完赛名次按实际冲线顺序确定。尚未冲线的对手会显示你冲线时的赛段进度。救援罚时计入个人计时成绩，不改变实际冲线顺序。暂停会冻结全部车辆，重新发车会将所有车辆恢复到起跑位置。

必须按顺序、沿正向、在赛道范围内通过全部 **5 个计时点**。抄近路绕过计时点不会记为通过；发生漏点时，救援会将车辆放回该计时点之前。

玩家车辆按自身朝向行驶。松开方向键后，转向力度平滑归零，并保留新的车头方向。镜头独立沿前方道路取景，因此能看到车头的转向与侧滑。

漂移时先积累车速，配合转向按住 `Space`。持续按住会逐渐增加侧滑角度，反打方向可以减小角度；松开 `Space` 后，车辆逐渐恢复抓地力，长按后的恢复过程更长。手刹始终产生制动，即使同时踩住油门也会减速。持续拉手刹最终会使车辆停下。

领航员路书中的 **2–3 表示较急的弯，4–5 表示较快的弯**。驶离道路会减速并损伤车辆。入弯前提前制动，出弯回正后再加速。

## 设置与存档

| 设置 | 说明 |
| --- | --- |
| 标准 / 轻量画质 | 轻量模式减少植被与像素密度，目标 30 fps；标准模式目标 60 fps |
| 俱乐部 / 专业难度 | 专业模式抓地力更低，对手更快，下次发车生效 |
| 自动油门 | 下次发车生效，刹车和手刹仍优先于油门 |
| 音效 / 领航员语音 | 合成引擎与砂石音效；中文路书播报取决于浏览器语音支持 |
| 镜头 | 沿道路方向的追尾视角或低位视角 |

最佳纪录按 **地图 × 车型 × 驾驶难度 × 油门模式** 分别保存，并兼容原松岭山道 / FALCON R4 的旧纪录。设置与成绩存储在当前浏览器本地，没有账号或云端同步。

游戏标签页失去焦点时会自动暂停，菜单和暂停场景按需渲染。车辆与镜头共用插值位姿；植被、对手车轮使用实例化，远处对手会被裁去，以控制渲染开销。

```text
src/

├── simulation/       赛道、玩家驾驶、AI 对手、计时与名次
├── render/           Three.js 场景、赛车、镜头、尘土与胎痕

├── main.ts           应用生命周期与各模块集成
├── input.ts          键盘与触屏输入

├── settings.ts       偏好设置与本地纪录
└── style.css         界面样式与响应式布局
tests/                Node.js 模拟与表现层检查
docs/screenshots/     两版 README 共用的截图与采集说明
```

常用命令：

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 在 5175 端口启动开发服务 |
| `npm run typecheck` | TypeScript 类型检查，不生成文件 |
| `npm test` | 运行 Node.js 测试 |
| `npm run build` | 类型检查并构建到 `dist/` |
| `npm run preview` | 在本地预览生产构建 |

测试覆盖手动转向、持续手刹、速度上限、计时点、排名、AI 避让、暂停与重开、存档、镜头稳定性、位姿插值和资源释放。测试仅在 Node.js 中运行，不打开浏览器，也不创建 WebGL 上下文。

**项目约定：不要启动游戏验证。** 使用 Node.js 检查与生产构建。

## 实现范围与常见问题

当前为 AI 对手参与的街机拉力玩法，不包含在线多人联机。AI 会主动避让，但尚未实现车辆碰撞冲量、完整轮胎物理、悬架模拟或场景物体碰撞。

若页面提示图形引擎不可用，请检查浏览器是否支持 WebGL 2，以及硬件加速是否开启。设备性能不足时，可选择轻量画质，并只保留一个游戏标签页。领航员语音的可用性取决于浏览器和系统。
