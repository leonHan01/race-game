# DUSTLINE · 尘途拉力

[English](README.md) · **简体中文**

一款包含室外山野赛道与三个室内封闭场馆的 3D 浏览器拉力竞速游戏。从砂石山道、松林、峡谷和雪岭驶入机库、穹顶赛事馆与仓储场馆，驾驶你选择的赛车，与 5 位 AI 车手争夺冲线名次，刷新个人赛段成绩。

使用 **Three.js、TypeScript 和 Vite** 开发。游戏菜单、HUD 与可选领航员语音目前为中文，项目提供中英文两版说明文档。

## 游戏特色

- **六车同场竞速**：5 位 AI 对手使用不同车型与驾驶节奏，会弯前制动、跟车和寻找空位超车。
- **十张不同难度的竞速地图**：七条室外路线（其中三张支持起伏飞跃）、三个室内封闭场馆，路宽 14–22 米，各有不同的弯道、环境和抓地力。
- **汽车与摩托车模式**：四款汽车、两款摩托可选，AI 同步使用对应车辆。摩托配有骑手、双轮模型与转向压弯，运动款和越野款操控不同。
- **手动控制车头方向**：转向输入平滑过渡，没有自动转弯或自动回到路中央。
- **按住空格持续手刹**：按得越久，侧滑角度逐渐增大；松开后逐渐恢复抓地力。
- **漂移积攒氮气**：侧滑时蓄能，按住 Shift 或仪表内的氮气按钮快速加速。
- **随地形自然飞跃**：汽车、摩托和五位 AI 对手都能加速迎坡腾空，具备重力下落、落地接触与腾空状态显示。
- **平稳的道路视角**：提供追尾和低位镜头，车辆运动经过插值，不添加画面抖动或悬架弹跳。
- **竞速与计时挑战**：实时名次、冲线顺序、五个分段成绩、完赛奖牌和本地最佳纪录。
- **山野拉力氛围**：自然光照、程序生成的场景与赛车、尘土尾流、渐隐胎痕、引擎声和领航员路书。

## 快速开始

运行环境：

- Node.js **20.x 分支的 20.19+，或 22.12 及以上版本**。
- npm。
- 支持 **WebGL 2** 且开启硬件加速的浏览器。

在项目目录执行：

```bash
npm ci
npm run dev
```

打开 **[http://localhost:5175/](http://localhost:5175/)**。

开发端口固定为 `5175`。如果端口已被占用，Vite 会明确报错，不会自动切换。请通过 Vite 访问游戏，直接双击文件系统中的 `index.html` 无法正确启动。

构建并预览生产版本：

```bash
npm run build
npm run preview
```

构建结果位于 `dist/`，预览地址以终端输出为准。需要发布时，可将 `dist/` 部署到静态网站托管服务。字体随项目打包，场景资源在本地生成，游戏运行时不依赖远程模型或图片服务。

## 操作方式

| 操作 | 键盘 |
| --- | --- |
| 油门 | `W` / `↑` |
| 刹车 | `S` / `↓` |
| 左转 / 右转 | `A` / `D`，或 `←` / `→` |
| 持续手刹 / 漂移 | 按住 `Space`，松开后恢复抓地力 |
| 氮气加速 | 按住左 / 右 `Shift` 或氮气按钮，通过漂移补充 |
| 使用道具 | 道具赛中按 `E` 或点击左侧道具栏 |
| 切换追尾 / 低位镜头 | `C` |
| 救援回赛道 | `R`，计时罚时 5 秒 |
| 暂停 / 继续 | `Esc` / `P` |

触屏设备提供转向、油门、刹车、手刹和氮气按钮。设置中可以开启自动油门，专注转向和制动；自动油门不会替你转弯。

在主菜单点击「选择地图」或「选择车辆」，再点击「开始赛段」。地图目录提供「全部赛道」「室外山野」「室内场馆」「起伏飞跃」筛选，点击「起伏飞跃」可找到新增坡道赛段，点击「室内场馆」可找到三个封闭赛场。比赛中需要先返回主菜单，才能切换地图或车辆。

### 起伏与飞跃

08–10 号赛道加入连续上坡、下坡和圆顶土坡。黄色 **JUMP** 路牌和领航员 HUD 会提前提示坡顶；地图卡片展示海拔曲线和跳台位置。不需要额外跳跃按键：低速可以贴地通过，加速迎坡会自然腾空，速度越高，飞跃距离和时间越长。起跳前摆正车头，为落地后的制动留出距离。

车辆离地后保留水平方向的惯性，受重力作用回落；转向、轮胎制动、漂移蓄能和氮气加速在接地后恢复。HUD 显示腾空时间和离地高度，飞行时停止产生地面尘土和胎痕，影子保持在路面上。镜头保持朝向道路，落地时平滑回落，不加入冲击抖动或反弹。原有赛道保留原先的贴地驾驶表现。

## 摩托车模式

在主菜单或车库点击「摩托车模式」，选择 **APEX R600** 运动摩托或 **TRAIL X450** 越野摩托，然后开始赛段。切回「汽车模式」即可继续驾驶汽车；比赛中需要先返回主菜单再换车。摩托选择与涂装自动保存，成绩按车型独立记录。

`W / ↑` 油门、`S / ↓` 刹车、`A / D` 转向压弯，`Space` 后轮制动。转向配合后刹滑胎可积攒氮气，松开后刹再按住 `Shift` 加速。运动摩托加速更快，越野摩托路肩减速和损耗较低；摩托滑胎幅度比汽车小。骑手和车身一起倾斜，追尾与低位镜头保持平稳。全部常规赛道支持摩托的经典竞速和道具赛，5 位 AI 对手会换成摩托。

## 竞速与漂移规则

六辆车在同一倒计时结束后起步。AI 会依据前方弯道与路面抓地力调整速度，选择相邻空位超车，或在前车后方减速跟随。专业模式下，对手的驾驶节奏更快。

HUD 显示实时名次和对手距离，完赛名次按实际冲线顺序确定。尚未冲线的对手会显示你冲线时的赛段进度。救援罚时计入个人计时成绩，不改变实际冲线顺序。暂停会冻结全部车辆，重新发车会将所有车辆恢复到起跑位置。

必须按顺序、沿正向、在赛道范围内通过全部 **5 个计时点**。抄近路绕过计时点不会记为通过；发生漏点时，救援会将车辆放回该计时点之前。

玩家车辆按自身朝向行驶。松开方向键后，转向力度平滑归零，并保留新的车头方向。镜头独立沿前方道路取景，因此能看到车头的转向与侧滑。

漂移时先积累车速，配合转向按住 `Space`。持续按住会逐渐增加侧滑角度，反打方向可以减小角度；松开 `Space` 后，车辆逐渐恢复抓地力，长按后的恢复过程更长。轮胎接地时，手刹始终产生制动，即使同时踩住油门也会减速。持续拉手刹最终会使车辆停下。

每场比赛的氮气从空槽开始。车辆有速度时转向拉手刹漂移即可蓄能，侧滑越明显积攒越快；直线拉手刹或停车不会蓄能。按住左 / 右 `Shift` 或速度表下方的氮气按钮即可加速，松开立即停止消耗，满槽可持续约 4 秒。氮气额外提供 40 m/s² 加速度，车辆完好时极速提高 70 km/h；松开或耗尽后平滑回落到常规极速。排气口喷出动态蓝白火芯与橙色外焰，镜头渐变广角、轻微横向压缩，配合画面边缘速度线，仪表保持清晰。系统开启「减少动态效果」时关闭画面冲刺特效。刹车或手刹会中断加速且不消耗氮气，暂停与救援保留余量，重新发车清空。

领航员路书中的 **2–3 表示较急的弯，4–5 表示较快的弯**。驶离道路会减速并损伤车辆。入弯前提前制动，出弯回正后再加速。

## 道具赛

主菜单选择「道具赛」，再点击「开始道具赛」。现有室内、室外赛道均会布置三列蓝色问号道具箱，以及青色箭头加速带。驶过道具箱后抽取一个道具，约 0.8 秒揭晓；按 `E` 或点击道具栏使用。道具未用完时不会覆盖，箱子被拾取后约 2.5 秒刷新。加速带自动提供 1.4 秒冲刺。

| 道具 | 效果 |
| --- | --- |
| 涡轮冲刺 | 强力加速 3 秒，仍遵守车型极速，刹车和手刹优先 |
| 香蕉陷阱 | 在车后留下香蕉皮，碰到的车手短暂打滑减速 |
| 直射飞盘 | 沿当前车道向前飞行，命中前方车手 |
| 追踪飞盘 | 锁定前方 180 米内最近的车手，追随其变道；无目标时保留道具 |
| 能量护盾 | 最长持续 7 秒，抵挡一次飞盘、香蕉或雷电攻击 |
| 雷电脉冲 | 使前后 180 米内的其他未完赛车手减速 |

AI 也会拾取和使用道具，落后车手更容易抽到冲刺、追踪飞盘和雷电。受击后获得短暂保护，避免连续受击；道具不损伤车辆、不增加罚时。暂停会冻结道具和计时，救援清除受击减速及道具冲刺，重开清空所有道具、飞盘和陷阱。经典竞速与道具赛分别保存最佳成绩，原有经典纪录继续有效。

道具箱、地面标记、飞盘、香蕉和护盾使用共享几何体与实例化绘制，只显示附近道具；飞盘和陷阱有数量上限与过期回收。

板型拥有不同的板面轮廓、板长、宽度、轴距和轮色；转向、抓地、蹬地、制动及耐损参数影响实际操控。三种涂装改变滑手服装和板面饰条。

| 操作 | 键盘 |
| --- | --- |
| 蹬地起步（约 32 km/h 以下有效） | `W` / `↑` |
| 重心转向 | `A` / `D` 或 `←` / `→` |
| 脚刹减速 | `S` / `↓` |
| 扶地刹滑，配合方向键做脚跟侧／脚尖侧动作 | 按住 `Space` |
| 站立式 speed check，较轻的减速与张臂平衡 | 按住 `X` |
| 180° 滑转，切换 Regular / Switch 站姿 | 双击或长按 `空格`、`Q`，或「180° Switch」按钮 |
| 收身降低风阻，松开恢复站姿 | 按住 `Shift` 或右下角收身按钮 |

新增刹滑包含屈膝预压、肩臂反向配合、手套触地及收板恢复。在约 11 km/h 以上双击空格（或按 Q）可立即触发 180° 滑转；持续按住空格 0.6 秒会先扶地刹滑，再自动转入 Switch 的另一侧。人和板一起转向，板头板尾调换、原后脚成为前脚，继续沿原方向下坡。松开后才能再次触发；换站姿后，蹬地与脚刹会交换用脚，方向键仍保持原来的转向方向。暂停冻结动作，救援保留已完成的站姿，重开恢复 Regular。动作参考与游戏映射见 [长板动作说明](docs/longboard-actions.md)。

坡度重力会自然加速；收身减少风阻，不消耗能量。脚刹与横板优先于蹬地和收身，可持续制动至停车。驶离柏油路会显著减速并损失状态。速度上限随板型变化（92–120 km/h），本模式没有氮气或道具。设置中的「自动蹬地」只在低速时推动长板。

沿用五个顺序计时点、冲线排名、奖牌、暂停、重新出发及 `R` 救援（罚时 5 秒）。HUD 显示滑手状态、滑行姿态、坡度和下降高度；纪录按速降模式、地图、板型、难度及自动蹬地设置分别保存。长板地图和型号会记住上次选择；切回经典竞速或道具赛会恢复此前选择的汽车或摩托车与地图。

## 设置与存档

| 设置 | 说明 |
| --- | --- |
| 标准 / 轻量画质 | 轻量模式减少植被与像素密度，目标 30 fps；标准模式目标 60 fps |
| 俱乐部 / 专业难度 | 专业模式抓地力更低，对手更快，下次发车生效 |
| 自动油门 | 下次发车生效，刹车和手刹仍优先于油门 |
| 音效 / 领航员语音 | 合成引擎与砂石音效；中文路书播报取决于浏览器语音支持 |
| 镜头 | 沿道路方向的追尾视角或低位视角 |

最佳纪录按 **比赛模式 × 地图 × 车型 × 驾驶难度 × 油门模式** 分别保存，并兼容原松岭山道 / FALCON R4 的旧纪录。设置与成绩存储在当前浏览器本地，没有账号或云端同步。

游戏标签页失去焦点时会自动暂停，菜单和暂停场景按需渲染。车辆与镜头共用插值位姿；植被、对手车轮使用实例化，远处对手会被裁去，以控制渲染开销。

## 实现范围与常见问题

当前为 AI 对手参与的街机拉力玩法，不包含在线多人联机。AI 会主动避让，室内外墙会限制玩家驶出场馆。尚未实现车辆碰撞冲量、完整轮胎物理、悬架模拟，以及场内装饰和赛道护栏的碰撞。

若页面提示图形引擎不可用，请检查浏览器是否支持 WebGL 2，以及硬件加速是否开启。设备性能不足时，可选择轻量画质，并只保留一个游戏标签页。领航员语音的可用性取决于浏览器和系统。
