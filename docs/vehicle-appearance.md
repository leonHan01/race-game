# 车辆外观与离线预览

汽车与摩托车继续使用 Three.js 程序化几何，细节按现有材质合并。更新保留车型尺寸、轮胎接地点、换色、转向和排气火焰接口。

- 汽车：区分小钢炮短尾翼、拉力车车顶进气、跑车低位格栅与贯穿尾灯、皮卡护板与竖向尾灯；补充机盖散热口、双辐轮毂和卡钳。
- 前后保险杠上的格栅、灯组和下包围按横向细分后弯曲，避免大三角面穿入车壳。细分面没有增加材质批次。
- 摩托车：渐变截面构建油箱、整流罩和尾壳；赛道车使用弧形风挡、双灯、后视镜和随前叉转动的挡泥板；越野车使用高挡泥板、双层灯组、护手、护底与交叉辐条。
- 两台摩托车补充排气弯管、链条、后减震弹簧、制动盘、仪表、头盔面罩和骑行服细节。小部件降低细分，玩家模型仍在原有 15 个网格、12,000 三角面预算以内。
- 选车页 SVG 同步细化轮毂、制动盘、车灯、风挡和护具。

第二轮细化：

- 车窗增加上下密封条与渐宽的后侧车柱；SWIFT 的车顶后缘延长，形成更明确的掀背轮廓。皮卡增加尾门把手。
- 汽车轮圈按车型区分：跑车采用更大轮圈与双辐条，掀背车采用八辐条，皮卡采用小轮圈与六根宽辐条。轮胎外径保持不变，玩家胎面增加环形沟槽。
- 辐条由平面改为内凹曲面，轮桶、刹车盘和孔位用顶点颜色区分深浅，继续共用金属材质；玩家、对手和离线导出均传入实际车型。
- 摩托车前胎收窄、后胎加宽，仍共享轮胎几何；运动版前叉增加暖金色金属效果。
- 骑手改用渐变半径、圆滑端部的四肢与收腰躯干，补齐肩颈衔接，调整头盔比例、贴合肩部的护具和黑色手套。运动版补充背部隆起，头盔加入随涂装换色的细条纹。
- CPU 预览同步读取顶点颜色；几何检查确认使用顶点颜色的材质拥有完整且有效的颜色属性，避免实际渲染时出现黑色部件。

第三轮细化：

- 汽车增加机盖肩线与内收腰线，跑车前后轮拱更饱满；门缝、渐宽侧饰条、机盖分缝与散热口随车身曲面贴合，后扩散器增加向上收起的底面和纵向导流片。
- 车门号码由平面贴片改为曲面网格；离线射线检查覆盖四台汽车两侧，确认贴花位于车壳外侧，左右文字方向一致。
- 摩托车油箱、整流罩和尾壳插入平滑过渡截面，修正纵向接缝法线；运动版深色通风区、斜向饰条和两台车的尾壳饰条按底层三角面裁切，避免饰面穿壳，补充整流罩紧固件。
- 选车页同步渐宽车门饰条、摩托车斜向侧饰面与尾壳细条纹。保持已有材质合批和几何预算。

新增车型（汽车目录扩展为 7 款，摩托保留 2 款）：

- **THUNDER V8**：长机盖、隆起进气口、四圆灯、五辐轮毂、双赛车条纹与鸭尾；后驱、245 km/h，漂移幅度更大，需提前制动。
- **VORTEX GT**：低矮短座舱、后部发动机散热栅、侧进气、前分流板、高尾翼与大轮圈；后驱、250 km/h，加速与制动更强，路肩损耗更高。
- **SUMMIT X4**：高顶完整后舱、独立后侧窗、行李架、低矮行李箱、涉水喉和护板；四驱、200 km/h，耐损、路肩减速少，转向较慢。
- 车库 SVG、动态车型数量、存档选择和独立成绩同步接入。五位汽车 AI 中加入这三款车型，保留六车同场；肌肉车车手配速设为 1.02。
- 新车型玩家模型为 16,234 / 16,584 / 16,058 三角面；对手版本为 4,696 / 4,752 / 4,712 三角面。对手车身纵向采样采用 32 段，保持原有 4,800 面与 5 个车身材质批次预算。五辆汽车对手共 23,552 面、35 个网格。
- 预览画布按实际车型数扩展行数，九款车均可完整展示。

上一轮模型优化（曲面与索引合批）：

- 掀背车、跑车与肌肉车的尾翼改为封闭弧面翼型，具备圆润前缘、渐薄尾缘和完整的上下表面；前缘接缝法线连续，避免高光出现硬折线。
- THUNDER 的机盖进气改为前高后低的收窄曲面，增加凹入式进气口和微凸圆灯透镜。VORTEX 的侧进气扩大到车门后方，车身腰线同步内收，饰面贴合凹面。
- 车顶增加弧度，侧窗与车柱随车顶边缘抬升；修正 VORTEX 车柱位置。车窗使用同一材质内的渐变顶点色。
- NOMAD 与 SUMMIT 增加黑色轮眉及固定螺钉；玩家轮毂补齐辐条侧面，轮胎侧壁细环改为低面数环带。车库 SVG 同步曲面尾翼、进气口和轮眉。
- 合并几何时保留原有索引、UV 接缝、法线与顶点色，不再把所有三角面展开成独立顶点。汽车玩家模型的独立几何缓冲数据降低约 **59%–62%**，对手降低约 **55%–60%**；共享此合并函数的摩托车也同步受益。没有增加材质批次、改变车轮接地点或排气口。

本轮细化（后视镜、雨刷与胎纹）：

- 七款汽车的后视镜采用前窄后宽的流线外壳、连续黑色包边和内嵌椭圆镜面，跑车镜壳更扁。端点使用三角扇，移除零面积三角面，并平滑端点和纵向接缝处的法线；对手版本保留镜面轮廓。
- 前雨刷和下沿饰板改为采样各车型实际挡风玻璃曲面，适配肌肉车、低矮超跑和高顶 SUV。掀背车与 SUV 增加后雨刷和随原刹车灯一同变亮的高位刹车灯。
- 非肌肉车的投射灯增加锥形反光杯和微凸透镜，同时减少原灯圈的细分。下进气口补齐横向叶片；SWIFT 使用 C 形尾灯，车尾补充不发光的倒车灯灯片、红色反光片与面板分缝。
- 玩家轮胎增加沿多边形胎肩贴合的斜向胎纹，皮卡与 SUV 的纹路更宽、更密。胎纹使用原橡胶材质的顶点颜色，四只车轮仍共享几何，轮胎接地半径保持 0.46。顶点着色只在汽车装配时启用，摩托车继续使用原橡胶材质设置。
- 选车页 SVG 同步流线后视镜、分段尾灯、下进气口和越野胎纹。前后离线预览及三款新增车辆的展示图均已更新。

```sh
python3 scripts/render-vehicle-preview.py /tmp/vehicle-preview.json docs/previews/vehicles-front.png
python3 scripts/render-vehicle-preview.py /tmp/vehicle-preview.json docs/previews/vehicles-rear.png --rear
```
