## Capture notes / 采集说明

The screenshots were captured from the already-open game page on `http://localhost:5175/`, following the request to continue screenshot capture. The menus were opened and the starting grid was displayed for the images; no driving test was performed. The game was returned to its main menu afterward. The in-game interface is currently in Chinese.

根据继续截图的请求，从已经打开的 `http://localhost:5175/` 游戏页面直接采集。为截图打开了菜单、车库和起跑区，没有进行驾驶测试；完成后已返回主菜单。游戏界面目前为中文。

Stage and vehicle catalogs scroll vertically; their screenshots show the top portion of the actual interface. The `race.jpg` caption identifies the starting grid rather than claiming a moving race or drift.

地图和车辆目录可以纵向滚动，截图展示实际界面的上半部分。`race.jpg` 展示发车列队，不代表车辆已经高速行驶或进入漂移。

When replacing an image, keep the filename and update the captions in both root READMEs if its contents change. Add only genuine game screenshots and keep image extensions consistent with their encoded format.
